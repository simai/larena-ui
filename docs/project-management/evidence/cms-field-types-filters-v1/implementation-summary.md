# Implementation summary

- The runtime bridge finds the CMS query form around the table, so table preferences and pagination connect on the CMS page as on the Dataview workbench.
- Long cell values end with an ellipsis inside their column; the Dataview stylesheet revision follows the change.
- ui.input declares input-type (text, date, datetime-local, time, number, email, tel, url).
- ui.checkbox names may end with [] so a group submits as a list.
